# leads — заказы для iamonline

Ищет людей, которым нужна разработка (Telegram-боты, Mini Apps, CRM, SaaS,
лендинги), и присылает новые запросы в Telegram. Только поиск и уведомления:
ничего не публикует, не комментирует, не пишет людям.

Cron (`crontab -l`): `*/20 * * * * node leads/run.mjs >> data/leads/cron.log`.

```
источники → свежесть → фильтр (match.mjs) → новые (seen.json) → Telegram + отчёт
```

## Источники

| Источник | Статус | Как | Лимит |
|---|---|---|---|
| `websearch` | выкл. (платный, отключён 2026-11-18) | Яндекс Поиск API: точные фразы «ищу разработчика бота», «посоветуйте crm для салона красоты»… за 60 дней; из выдачи берутся только UGC-площадки (otvet.mail.ru, стены/обсуждения VK, форумы, Хабр Q&A) | 2 запроса за прогон, раз в 3 ч; дневной `YANDEX_SEARCH_DAILY_LIMIT` (20); кэш 12 ч |
| `hn` | вкл. | Hacker News через Algolia: комментарии «SEEKING FREELANCER» из ежемесячного треда, EN | раз в 3 ч |
| `reddit` | вкл. | r/forhire, только `[Hiring]` | раз в час; с IP сервера Reddit обычно отвечает 404/429 — тогда пропуск |
| `telegram` | выкл. | публичные каналы через `t.me/s/<канал>` | раз в 30 мин |
| `kwork`, `flru` | выкл. | биржи | — |

Почему выключены:
- **Kwork, FL.ru** — демпинг и огромная конкуренция.
- **Telegram-каналы** — проверены 16 «заказных» каналов: за 14 дней 0 подходящих
  сообщений (вакансии в штат, дизайн, дайджесты). Чаты, где пишут сами
  заказчики, превью `t.me/s` не имеют (302) — без логина их не прочитать.
- **Проверены и не взяты:** hh.ru API (403 с этого IP), Хабр Фриланс (закрыт),
  freelancer.com и прочие биржи (та же проблема, что с Kwork).

Включить источник обратно: `"enabled": true` в `config.json`. Собирать в отчёт
без Telegram: `"notify": false`.

## Фильтр (`match.mjs`)

1. Услуга: бот / Mini App / CRM / SaaS / лендинг.
2. Стоп-слова: парсеры, накрутки, крипта, CMS (Битрикс, Tilda, WordPress),
   игровые RP-проекты, капчи, вакансии в штат, реклама каналов.
3. Для свободного текста (поиск, HN, каналы) — **намерение**: «ищу / нужен /
   посоветуйте / кто сделает» рядом с услугой; самопрезентации («сделаю бота»,
   «моё портфолио», «под ключ от 15 000 ₽») и риторические заголовки статей
   («Кому нужен чат-бот?») отбрасываются.
   Отдельный сигнал — **уход с конструктора записи**: «альтернатива /
   аналог / подорожал» рядом с YCLIENTS, DIKIDI, Altegio и др. Это лид на
   CosmoDesk/BodyTime, а не заказ разработки.
4. Бюджет, если указан, — не ниже `minBudgetRub` / `minBudgetUsd`.

## Telegram-уведомления

1. В Telegram открыть @BotFather → `/newbot` → получить токен.
2. Написать своему боту любое сообщение.
3. Открыть `https://api.telegram.org/bot<токен>/getUpdates`, взять
   `result[0].message.chat.id`.
4. В `.env` в корне репозитория (chmod 600, не в git):
   ```
   LEADS_TG_BOT_TOKEN=…
   LEADS_TG_CHAT_ID=…
   ```
5. Готово — следующий прогон cron пришлёт новые заказы (до 10 за раз).
   Первый прогон после пустого `data/leads/seen.json` ничего не шлёт, только
   запоминает текущие.

## Добавить запрос или канал

- **Поисковая фраза** — в `sources.websearch.queries`. Работают точные фразы в
  кавычках от первого лица («ищу разработчика…», «посоветуйте…»): без кавычек
  выдача — SEO-статьи. Каждый запрос стоит денег: 24 фразы × 2 за прогон ×
  8 прогонов в день ≈ полный круг за 1,5 дня.
- **Площадка** — если запросы находят живые вопросы на новом сайте, добавить
  шаблон URL в `UGC` (`search/source.mjs`), мусорный сайт — в `DEFAULT_DENY`.
- **Telegram-канал** — в `sources.telegram.channels` (только если
  `https://t.me/s/<канал>` открывается) и `"enabled": true`.

## Запуск руками

```sh
node leads/run.mjs --dry-run --verbose          # без записи и уведомлений
node leads/run.mjs --dry-run --verbose --force  # игнорировать интервалы
node leads/run.mjs --only=hn,websearch
node --test leads/*.test.mjs
```

`--dry-run` всё равно тратит дневной бюджет Яндекса (запросы платные) и
пишет кэш.

## Данные

- `data/leads/YYYY-MM-DD.jsonl` — найденные за день.
- `data/leads/seen.json` — дедупликация, 60 дней.
- `data/leads/state.json` — время последнего опроса источников, курсор запросов.
- `data/leads/yandex-budget.json`, `data/leads/yandex-cache/` — бюджет и кэш поиска.
- `reports/leads-latest.md` — последние 7 дней.
