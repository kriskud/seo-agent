# Настройка приложения Meta для Threads-агента

Делается один раз, с компьютера. Понадобится: аккаунт Facebook (любой рабочий),
телефон с приложением Threads, залогиненным в аккаунт CosmoDesk.

Интерфейс Meta бывает на русском или английском — названия кнопок даю в обоих
вариантах. Если какой-то экран выглядит иначе, чем описано, — не страшно,
ориентируйся по названиям.

## Шаг 1. Кабинет разработчика

1. Открой https://developers.facebook.com и нажми **«Войти» / Log in** (справа сверху).
2. Войди через свой аккаунт Facebook.
3. Если сайт предложит «стать разработчиком» (**Get Started / Начать**) — соглашайся:
   подтверди телефон или почту, в качестве рода занятий можно выбрать
   **Owner / Founder**.

## Шаг 2. Создание приложения

1. Справа сверху нажми **My Apps / Мои приложения**, затем зелёную кнопку
   **Create App / Создать приложение**.
2. Название приложения: `CosmoDesk Threads Agent`. Почта — твоя.
3. На шаге про сценарий использования (**Use case / Сценарий использования**)
   выбери **Access the Threads API / Доступ к Threads API**.
4. Бизнес-портфолио подключать не нужно (если спросит — вариант
   **I don't want to connect... / Не подключать**).
5. Дожми мастер до конца кнопками **Next / Далее** и **Create app / Создать приложение».
   Может попросить пароль от Facebook — это нормально.

## Шаг 3. Разрешения Threads API

1. В левом меню приложения найди пункт **Use cases / Сценарии использования**
   и нажми **Customize / Настроить** напротив Threads API.
2. На вкладке **Settings / Настройки** сценария отметь галочками разрешения:
   - `threads_basic` (обычно уже включено)
   - `threads_content_publish`
   - `threads_manage_insights`
   - `threads_read_replies`
3. Если для сохранения потребуются **Redirect Callback URLs** — впиши
   `https://cosmodesk.ru/` во все обязательные поля про URL. Для нашего способа
   получения токена они не используются, но форма требует их заполнить.

## Шаг 4. App ID и App Secret

1. В левом меню: **App settings / Настройки приложения** → **Basic / Основное**.
2. Скопируй **App ID / Идентификатор приложения** — это `THREADS_APP_ID`.
3. Напротив **App secret / Секрет приложения** нажми **Show / Показать**
   (спросит пароль Facebook) и скопируй — это `THREADS_APP_SECRET`.
4. Сохрани оба значения в заметку — они понадобятся для файла на сервере.
   Никому их не пересылай и не вставляй в чаты.

## Шаг 5. Добавить себя тестировщиком

1. В левом меню: **App roles / Роли приложения** → **Roles / Роли**.
2. Нажми **Add people / Добавить людей**, выбери тип **Threads tester /
   Тестировщик Threads**.
3. Введи имя аккаунта CosmoDesk в Threads (без `@`) и отправь приглашение.

## Шаг 6. Принять приглашение в Threads

1. Открой https://www.threads.net в браузере (или приложение на телефоне),
   войди в аккаунт CosmoDesk.
2. Зайди в **Настройки** → **Аккаунт** → **Разрешения сайта / Website permissions**
   → **Приглашения / Invites**.
3. Прими приглашение от `CosmoDesk Threads Agent`.

## Шаг 7. Получить токен

1. Вернись в кабинет разработчика: **Use cases / Сценарии использования** →
   **Customize / Настроить** напротив Threads API → вкладка/раздел
   **User Token Generator / Генератор токенов пользователя**
   (иногда он лежит в разделе **Settings / Настройки** сценария).
2. Напротив аккаунта CosmoDesk нажми **Generate token / Создать токен**.
3. Появится окно с длинной строкой — это токен доступа. Нажми **Copy / Копировать**.
4. Токен живёт максимум 60 дней, дальше агент продлевает его сам. Токен — это
   ключ от аккаунта: не вставляй его никуда, кроме шага ниже.

## Шаг 8. Передать токен агенту

Выполнить в терминале на сервере 26s_kris (команды появятся после фазы 1;
скрипт `auth_bootstrap` попросит вставить токен невидимым вводом и напечатает
имя аккаунта и дату истечения — так поймём, что всё сработало).
