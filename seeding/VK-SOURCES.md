# Первичные VK-источники для CosmoDesk

Пользователь разрешил добавлять найденные подходящие VK-сообщества для discovery.
Проверено 2026-09-18. Список найденных кандидатов с источниками подтверждения:
`config/vk-candidates.json`. Этот файл не является активным allowlist и не читается
runtime-провайдером. Разрешение относится только к мониторингу: не к отправке
сообщений, комментариям, реакциям или вступлению в закрытые сообщества.

| Кандидат | Тематическое подтверждение | Что осталось проверить |
|---|---|---|
| [Я КОСМЕТОЛОГ](https://vk.com/gazetak) | [Сайт проекта](https://kosmetolog.today/) сам ссылается на этот VK-адрес | Numeric ID, публичная доступность стены, свежие записи/вопросы об организации практики |
| [Клуб косметологов России](https://vk.com/club.kosmetologov) | [Публичная страница клуба](https://t.me/clubkosmetologov) указывает аудиторию косметологов и этот VK-адрес | Numeric ID, публичная стена, свежесть и полезность записей |

В доступном поиске не подтверждены конкретные свежие жалобы на YCLIENTS/DIKIDI
в этих сообществах. Выбор основан на профессиональной аудитории, а не на
выдуманной оценке качества выдачи. Нужны реальные результаты перед расширением.

Прямая загрузка страниц VK без авторизации вернула generic страницу
«Vkontakte | VKontakte», без проверяемых данных сообщества. Посторонние числовые
ID из общего JS страницы не используются как communityId. Поэтому ID оставлены
null, `config/vk.json` по-прежнему содержит пустой communityIds и enabled=false.

После появления разрешённого VK API token: разрешить именно эти screenName,
проверить тип community и публичность, закрепить подтверждённые positive numeric
IDs в `vk.json` и сохранить результаты проверки в candidates. Только после этого
включать `wall.search`. Переименованный/закрытый/удалённый или неподходящий ресурс
не включается. Для найденных и подтверждённых подходящих сообществ пользователь
уже разрешил добавление; отдельное разрешение на posting не предоставлено.

Telegram allowlist не расширялся. Публичная веб-страница клуба использовалась
только как источник ссылки на VK; личная Telegram-сессия не использовалась.
